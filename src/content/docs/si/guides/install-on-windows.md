## ක්‍රියාත්මක පරිසරය තෝරන්න

වත්මන් `main` සඳහා PHP 8.4+, `pcntl` සහ `posix` අවශ්‍යයි; දේශීය Windows PHP මෙම Unix දිගු අවශ්‍යතා සපුරාලන්නේ නැත. Composer වේදිකා පරීක්ෂණ මඟ නොහරින්න. Linux VM එකක් භාවිත කරන්න, නැතහොත් Microsoft සහාය ඇති Windows මත WSL 2 ඇගයීමට ලක් කරන්න. මේවා Windows විසින් සත්කාරකත්වය දරන Linux ස්ථාපන වන අතර තහවුරු කළ දේශීය IIS යෙදවීම් නොවේ. PHP වේදිකා සීමා බලන්න.

## Linux සූදානම් කර ස්ථාපනය කරන්න

WSL සඳහා පරිපාලක PowerShell තුළ මෙය ධාවනය කර ඉල්ලා සිටියහොත් නැවත ආරම්භ කරන්න:

```powershell
wsl --install -d Ubuntu
wsl --list --verbose
```

අනුවාදය 2 බව තහවුරු කරන්න. Linux ගිණුම සකසා Linux තුළ ස්ථාපන මාර්ගෝපදේශය අනුව දත්ත සමුදාය, PHP දිගු, සම්පත්, වෙබ් සේවාදායකය සහ කාලසටහන සකසන්න. කේතය සහ RRD Linux ගොනු පද්ධතියේ තබන්න; `/mnt/c/` යටතේ නොතබන්න. Microsoft WSL සහ ගොනු පද්ධති මාර්ගෝපදේශ බලන්න.

## ජීවන චක්‍රය සහ ප්‍රතිසාධනය පරීක්ෂා කරන්න

කැපවූ වරප්‍රසාද රහිත ගිණුම් සහ එක රැස්කිරීම් ආරම්භක ක්‍රමයක් භාවිත කරන්න. ධාරකය නැවත ආරම්භ කළ හෝ WSL වසා දැමූ පසු ගබඩා විශ්වාසය, polling, ප්‍රස්තාර වේලා මුද්‍රා සහ නැවත ආරම්භක හැසිරීම තහවුරු කරන්න. ඩෙස්ක්ටොප් සැසියක් රැස්කිරීම දිගටම පවත්වාගනී යැයි නොසිතන්න. දත්ත සමුදාය, වින්‍යාසය සහ RRD එකට උපස්ථ කරන්න. දේශීය Windows හි විනාශකාරී RRD නඩත්තුව සහ ස්වයංක්‍රීය දේශීය මැකීම/සංරක්ෂණය තවම නොමැත; Linux හැසිරීමෙන් ඒවා තහවුරු නොවේ. අවශ්‍යතා සහ උපස්ථ බලන්න.
