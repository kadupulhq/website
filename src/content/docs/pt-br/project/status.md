O Kadupul está em fase pré-alfa. O código está disponível, mas não existe uma versão com suporte para produção nem uma migração validada. Não o utilize em produção.

Esta página é um resumo. Consulte a página completa em inglês para obter mais informações. [English](/project/status/)

## Estado do projeto

O aplicativo deriva do Cacti 1.2.31. A branch main contém o desenvolvimento; lts/1.2 recebe correções e melhorias de segurança. A política de versões prevê v1.3.0 e v1.2.32 para essas branches. Um número previsto não demonstra que uma versão tenha sido publicada.

O Kadupul manterá uma derivação do Spine. O repositório e as compilações validadas ainda precisam ser documentados. A compatibilidade de extensões, modelos, bancos de dados e arquivos RRD é um objetivo que exige testes.

Consulte as políticas do repositório para conhecer os compromissos atuais. Os testes automatizados e as ferramentas de criação de pacotes, por si só, não demonstram que uma migração seja segura.
