## Estado del proyecto

La aplicación deriva de Cacti 1.2.31. La rama main contiene el desarrollo; lts/1.2 recibe correcciones y mejoras de seguridad. La política de versiones contempla v1.3.0 y v1.2.32 para esas líneas. Un número previsto no demuestra que exista una versión publicada.

Kadupul mantendrá una bifurcación de Spine. Su repositorio y las compilaciones validadas aún deben documentarse. La compatibilidad de complementos, plantillas, bases de datos y archivos RRD es un objetivo que exige pruebas.

Consulta las políticas del repositorio para conocer los compromisos actuales. Las pruebas automatizadas y las herramientas de empaquetado no demuestran por sí solas que una migración sea segura.
