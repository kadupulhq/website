වැඩ ලැයිස්තුව පූර්ව ගණනය කර ඇති අතර එකතු කරන්නා සෑම චක්‍රයකදීම ඔබේ වින්‍යාසය ඇගයීමට
ලක් කරනවා වෙනුවට එම ලැයිස්තුව කියවයි. මෙම පිටුව ප්‍රායෝගිකව එම තීරණයේ සැබෑ බලපෑම
පිළිබඳව සාකච්ඡා කරයි.

## එකතු කරන්නාට එසේ නොමැති නම් කිරීමට සිදුවන දේ

තනි අගයක් සඳහා එකතු කළ යුතු දේ තීරණය කිරීම සඳහා සම්පූර්ණ යැපීම් දාමයක් විසඳිය යුතුය.
දත්ත මූලාශ්‍රය උපාංගයක් සහ දත්ත ආකෘතියක් වෙත යොමු කරයි. ආකෘතිය දත්ත ආදානයක් වෙත
යොමු කරයි. දත්ත ආදානයෙහි ක්ෂේත්‍ර ඇති අතර, ඒවායින් සමහරක් උපාංගයකට අභිබවා ගොස් ඇති
අතර සමහරක් ආකෘතියෙන් උරුම වී ඇත. දත්ත මූලාශ්‍රය දත්ත විමසුමකින් පැමිණියේ නම්, වත්මන්
දර්ශකය විමසුම් හැඹිලිය හරහා විසඳිය යුතුය. එවිට ක්ෂේත්‍රයක් ඒවා අභිබවා නොයන්නේ නම්
උපාංගයෙන් SNMP අක්තපත්‍ර ලබා ගත යුතුය.

එය තනි අගයක් සඳහා බහු සම්බන්ධ කිරීම් (joins) වේ. සාමාන්‍ය ස්ථාපනයක අගයන් දස දහස් ගණනක්
ඇති අතර සෑම මිනිත්තු පහකට වරක් චක්‍රයක් ක්‍රියාත්මක වේ. එකතු කිරීමේදී මෙම විසඳීම සිදු
කිරීමෙන් අදහස් වන්නේ ඔබට නිරීක්ෂණය කළ හැකි උපාංග ගණන තීරණය කරන්නේ ජාලය නොව දත්ත
සමුදාය බවයි.

එබැවින් විසඳීම සිදුවන්නේ යමක් වෙනස් වූ විට එක් වරක් පමණක් වන අතර ප්‍රතිඵලය පැතලි ලෙස ලියා තබයි.

## මොට මෙවලම

තනි උපාංගයක් සඳහා, එහි උරුම උපාංග පිටුවේ **පෝලර් හැඹිලිය නැවත පුරවන්න** භාවිතා කරන්න.
එම ක්‍රියාව උපාංග විෂය පථය සහිත `push_out_host()` මාර්ගය අමතයි. පසුව ප්‍රතිඵලයක් ලෙස
ලැබෙන පේළි සහ රෝග විනිශ්චය පරීක්ෂා කරන්න.

වත්මන් මව් ස්ක්‍රිප්ට් `rebuild_poller_cache.php` `--host-id` පිළිගන්නා නමුත් එම
පෙරහන එහි සේවක විධානයට යොමු නොකරයි. එබැවින් තනි උපාංගයක CLI නැවත ගොඩනැඟීමකින් වෙනත්
සක්‍රීය උපාංග නැවත ගොඩනැඟිය හැක. මෙම යෙදුම් දෝෂය නිවැරදි කරන තෙක් හුදකලා වීම සඳහා
එම විකල්පය මත රඳා නොසිටින්න.

පෝලර් පරිශීලකයා ලෙස ධාවනය වන යෙදුම් මූලයෙන් පුළුල් CLI නැවත ගොඩනැඟීමක් ලබා ගත හැක:

```bash
php cli/rebuild_poller_cache.php
```

එය සක්‍රීය උපාංග සකසයි; එය සෑම ධාරක රහිත හෝ අක්‍රිය මූලාශ්‍රයක් සඳහාම අලුත්වැඩියාවක් නොවේ.
මෙය එකතු කිරීමේ වගු වලට ලියන අතර කාලය ගත විය හැක. අතිච්ඡාදනය වන නැවත ගොඩනැඟීම් වළක්වා
ක්‍රියාවලියට බාධා නොකරන්න. CLI හි `--force` විකල්පය එහි ක්‍රියාවලි ලියාපදිංචි කිරීමේ

එකතුව පරීක්ෂා කරන්න.

හැඹිලිය අවසන් වරට වෙනස් වූයේ කවදාද යන්න Kadupul විසින් වාර්තා කරනු ලබන අතර, එමඟින්
