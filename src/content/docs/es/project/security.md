Comunica las vulnerabilidades en privado, también cuando afecten a código no publicado. No abras una incidencia pública ni publiques una corrección antes de la evaluación privada.

Esta página ofrece una introducción resumida. Consulta la página completa en inglés para más detalles. [English](/project/security/)

[Política de seguridad del repositorio](https://github.com/kadupulhq/kadupul/blob/main/SECURITY.md)

## Informar de una vulnerabilidad en privado

Incluye la versión o el commit, los pasos para reproducir el problema, la configuración necesaria y si hace falta autenticación. Los responsables procuran confirmar la recepción en tres días laborables; no es una fecha prometida de corrección.

[Informar de una vulnerabilidad en privado](https://github.com/kadupulhq/kadupul/security/advisories/new)

La política cubre la aplicación, el sondeador, el instalador y el empaquetado. Excluye plugins de terceros, RRDtool, Net-SNMP, el servidor web, la base de datos y casos que exijan que un administrador actúe contra su propia instalación.
