නැව්ගත කරන ලද ESXi පැකේජය ධාරක මිනුම් සහ ආගන්තුක ඉන්වෙන්ටරි ගණන් එකතු කරයි. එය ආගන්තුකයෙකුට CPU, මතකය හෝ ආරවුල් මිනුම් ලබා නොදේ. ප්‍රස්ථාර තේරීමට පෙර ඔබේ හයිපර්වයිසර් අනුවාදය මඟින් නිරාවරණය වන වස්තු තහවුරු කරන්න.

## පළමුව නියෝජිතයා ක්‍රියාත්මක කරන්න

පවතින නියෝජිත වින්‍යාසය සමාලෝචනය කර ඔබේ ESXi අනුවාදය සඳහා උපදෙස් භාවිතා කරන්න. පැකේජ සටහන් වල කර්මාන්තශාලා යළි පිහිටුවීමක් ඇතුළත් වේ; එය සාමාන්‍ය පූර්වාවශ්‍යතාවක් නොවන අතර පවතින SNMP වින්‍යාසය මකා දමනු ඇත. ප්‍රජාව පදනම් කරගත් සැකසුම සඳහා, පහත විධානයන් නියෝජිත අගයන් සකසයි; ප්‍රජා ලැයිස්තුව සැකසීමේදී උදාහරණ ප්‍රතිස්ථාපනය කර අවශ්‍ය ඕනෑම ප්‍රජාවක් ආරක්ෂා කරන්න.

```bash
esxcli system snmp get
esxcli system snmp set -c YOUR_STRING
esxcli system snmp set -p 161
esxcli system snmp set -L "City, State, Country"
esxcli system snmp set -C noc@example.com
esxcli system snmp set -e yes
```

පළමු විධානය වින්‍යාසය පෙන්වයි; අවසාන විධානය මඟින් නියෝජිතයා සක්‍රීය කරයි. ප්‍රජා විකල්පය එහි වින්‍යාස කළ ලැයිස්තුව ප්‍රතිස්ථාපනය කරයි. පෝලරයේ සිට අවශ්‍ය ෆයර්වෝල් ප්‍රවේශය පරීක්ෂා කර [ESXCLI SNMP විධාන යොමුව](https://developer.broadcom.com/xapis/esxcli-command-reference/latest/namespace/esxcli_system.html) බලන්න. මෙම විධානයන් ප්‍රජාව පදනම් කරගත් ඡන්ද විමසීම් වින්‍යාස කරයි; ඒවා SNMPv3 වින්‍යාස නොකරයි. උපාංගය එක් කිරීමට පෙර පෝලරය ධාවනය වන යන්ත්‍රයේ සිට තහවුරු කරන්න.

```bash
snmpget  -v2c -c YOUR_STRING esxi.example.net .1.3.6.1.2.1.1.1.0
snmpwalk -v2c -c YOUR_STRING esxi.example.net .1.3.6.1.2.1.25.3.3.1.2
snmpwalk -v2c -c YOUR_STRING esxi.example.net .1.3.6.1.4.1.6876.2.1.1.6
```

## ගණන් කිරීමේ ගැටළු

මෙය භෞතික සේවාදායකයකින් අථත්‍යකරණය වෙනස් කරන කොටස වන අතර, එයින් කිසිවක් ප්‍රස්ථාර ආකෘතියකින් විසඳෙන්නේ නැත.

**අමුත්තන් ගමන් කරයි.** වෙනත් ධාරකයකට සංක්‍රමණය වන ආගන්තුකයෙකු පළමු ධාරකයේ ඉන්වෙන්ටරියෙන් අතුරුදහන් වී දෙවැන්නෙහි දිස්වේ. ස්වාධීනව කාලානුරූප සාම්පල එම ආගන්තුකයා තාවකාලිකව දෙවරක් ගණන් කිරීමට හෝ මඟ හැරීමට ඉඩ ඇත. ගණන් කිරීමේ වෙනස්කම් පමණක් සංක්‍රමණය ඔප්පු නොකරයි: ඒවා පැහැදිලි කිරීමට හයිපර්වයිසර් ඉන්වෙන්ටරි අනන්‍යතා සහ සිදුවීම් භාවිතා කරන්න.

**සම්පත් බෙදාහදා ගනී, එබැවින් ආගන්තුකයෙකුට ආරෝපණය කිරීම ඇස්තමේන්තුවකි.** ධාරකය භෞතික ප්‍රොසෙසර භාරය වාර්තා කරයි. එයට හේතු වූ ආගන්තුකයා කවුරුන්ද යන්න වාර්තා නොකරයි. ධාරකයේ CPU ආගන්තුක ගණනින් බෙදීමෙන් අංක ගණිතමය වශයෙන් නිවැරදි සහ කිසිවෙකු නොඇසූ ප්‍රශ්නයකට පිළිතුරු සපයන අංකයක් ලැබේ.

**අධික ලෙස වෙන් කිරීම (Overcommit) මඟින් වෙන් කිරීම සහ භාවිතය වෙනස් ප්‍රමාණ බවට පත් කරයි.** පවරා ඇති අථත්‍ය CPU වලට භෞතික මධ්‍ය ඉක්මවිය හැකි අතර, පවරා ඇති මතකයට භෞතික මතකය හිතාමතාම ඉක්මවිය හැක. පවරා ඇති සම්පත් ප්‍රස්ථාරයක් මනින ලද ඉල්ලුමට වඩා වෙන් කිරීම විස්තර කරයි. එය භෞතික ධාරිතාව, වින්‍යාස කළ සීමාවන් සහ සැබෑ භාවිතය සමඟ සසඳන්න.

**මෙම වගු වල ආරවුල් (Contention) නොපෙනේ.** ආගන්තුකයෙකු කුසගින්නේ සිටින බව පවසන මිනුම්, භෞතික ප්‍රොසෙසරයක් සඳහා බලා සිටි කාලය සහ ධාරකය එයින් නැවත ලබා ගත් මතකය, මෙම ආකෘතිය එකතු කරන දෙයෙහි නොමැත. දැඩි ලෙස තරඟ කරන අමුත්තන් සහිත සියයට 60 ක CPU හි ධාරකයක් සතුටු සිතින් සිටින අමුත්තන් සහිත සියයට 60 ක CPU හි ධාරකයකට සමාන ලෙස මෙහි දිස්වේ.

**ආගන්තුක සහ ධාරක මිනුම් විවිධ ප්‍රශ්න වලට පිළිතුරු සපයයි.** ආගන්තුක භාවිතය පමණක් ධාරක කාලසටහන්ගත කිරීමේ ප්‍රමාදයන් පැහැදිලි නොකරනු ඇත. ධාරක භාරයෙන් ආරෝපණය ලබා ගැනීමට වඩා හයිපර්වයිසර් ආරවුල් ප්‍රමිතික සමඟ ආගන්තුක/යෙදුම් මිනුම් සහසම්බන්ධ කරන්න.

## නැව්ගත කරන ලද ආගන්තුක ගණනයේ උගුල්

ආගන්තුක ඉන්වෙන්ටරි ස්ක්‍රිප්ටයේ ප්‍රතිදානය මත විශ්වාසය තැබීමට පෙර එය තේරුම් ගැනීම වටී.

**එය ඇවිදින්නේ SNMP අනුවාදය 1 සහ ප්‍රජා තන්තුව සමඟ පමණි.** අනුවාදය ස්ක්‍රිප්ටය තුළ නියම කර ඇති අතර උපාංගයේ v3 අක්තපත්‍ර ලබා නොදේ. ආගන්තුක එකතු කිරීම අසාර්ථක වන අතර v3 සඳහා වින්‍යාස කර ඇති උපාංගයකට වෙනත් මාර්ග හරහා එකතු විය හැක. එම නියෝජිතයා v1 හරහා ගබඩා කර ඇති ප්‍රජාව ස්වාධීනව පිළිගන්නේ නම් ආගන්තුක එකතුව තවමත් සාර්ථක විය හැක; උපාංගයේ v3 තේරීම පමණක් ප්‍රතිඵලය තීරණය නොකරයි. හිස් ආගන්තුක ඇවිදීම් බිංදු ලෙස ලබා දේ. සහායකයාට ඉඩ සැලසීම සඳහා නියෝජිතයෙකුගේ ආරක්ෂක ප්‍රතිපත්තිය පහත හෙලීමෙන් තොරව මෙම ප්‍රොටෝකෝල නොගැලපීම පරීක්ෂා කරන්න.

**ගණනය බල තත්ත්ව වගුවෙන් පැමිණේ.** ආගන්තුක එකතුව ලෙස වාර්තා වන සංඛ්‍යාව බල තත්ත්ව උප-ගස ඇවිදීමකින් ආපසු ලබා දුන් ඇතුළත් කිරීම් සංඛ්‍යාව මිස වෙනම ඉන්වෙන්ටරි වස්තුවක් නොවේ. ධාරකය ලැයිස්තුගත කරන නමුත් බල තත්ත්ව ඇතුළත් කිරීමක් නොමැති ආගන්තුකයෙකු ගණන් නොගනී.

**බලගන්වන ලද බව තත්ත්ව පෙළ මත ගළපනු ලැබේ.** කප්පාදු කිරීමෙන් සහ කුඩා අකුරට හැරවීමෙන් පසු, `powered on` සහ `poweredon` පමණක් ධාවනය වන ගණන වැඩි කරයි. වෙනත් නිරූපණයන් සිදු නොවේ; ශුන්‍යයක් අර්ථ නිරූපණය කිරීමට පෙර අමු නියෝජිත ප්‍රතිචාරය සසඳන්න.

**ආගන්තුක මෙවලම් වර්ගීකරණයේ තහවුරු වූ දෝෂයක් ඇත.** වචනාර්ථ `not installed` ධාවනය වන ලෙස ගණන් ගනු ලබන්නේ එහි ගැළපීම ශුන්‍ය ඕෆ්සෙට් එකෙන් ආරම්භ වන බැවිනි. හඳුනා නොගත් පෙළ ද ධාවනය වන තත්ත්වයට වැටේ. එම ගණන් කිරීම සෞඛ්‍ය සම්පන්න මෙවලම් පිළිබඳ සාක්ෂියක් ලෙස නොසලකන්න; [මෙවලම්-තත්ත්ව දෝෂය](https://github.com/kadupulhq/kadupul/issues/244) බලන්න.

**එය ඇමතුමකට තුන් වතාවක් ඇවිදියි.** එය බල-තත්ත්ව වගුව දෙවරක් කියවයි, පසුව මෙවලම් වගුව කියවයි, එබැවින් එහිම ගණන් කිරීම පවා පරමාණුක ඉන්වෙන්ටරි ස්නැප්ෂොට් එකක් නොවේ. බොහෝ අමුත්තන් සිටින ධාරකයෙකු මත, එම එකතු කිරීමේ පිරිවැය මැන බලන්න. පෝලරය තද නම්, නූල් වැඩි කිරීමට පෙර මෙය දිගු පරතරයක් සඳහා අපේක්ෂකයෙකි. [පෝලරය පරිමාණය කරන්න](/si/guides/scale-the-poller/) බලන්න.

ස්ක්‍රිප්ටය සාමාන්‍යයෙන් හිස් ඇවිදීම් සඳහා බිංදු ඇතුළුව නම් කරන ලද අගයන් පහම නිකුත් කරයි. එබැවින් අසාර්ථක ඇවිදීමකින් වාක්‍ය ඛණ්ඩමය වශයෙන් සම්පූර්ණ නමුත් නොමඟ යවන සාම්පලයක් ලබා දිය හැක. අසම්පූර්ණ ප්‍රතිදානය සඳහා, PHP ප්‍රතිදාන සකසනය සම්බන්ධිත දත්ත ප්‍රභවයට අවශ්‍ය ක්ෂේත්‍ර පරීක්ෂා කර අසම්පූර්ණ වේලාමුද්‍රා කණ්ඩායම් රඳවා තබා ගනී; එය අනිවාර්යයෙන්ම ඒවා වහාම ඉවත නොදමයි. [පෝලර් හැඹිලිය](/si/concepts/the-poller-cache/) බලන්න.

## ඉතිරියෙහි ඇති උගුල්

**ප්‍රොසෙසරයේ සාමාන්‍යය අසමතුලිතතාවය සඟවයි.** එක් අධික ලෙස භාවිතා වන මධ්‍යයක් සහ අක්‍රිය මධ්‍ය 63 ක් සහිත ධාරකයක් අඩු සාමාන්‍යයක් පෙන්වයි. එය වැදගත් වන වලංගු ප්‍රොසෙසරයකට ප්‍රස්ථාර තබා ගන්න. සාමාන්‍ය සහායකයා හිස් ඇවිදීමක් සඳහා `load:0` ලබා දෙයි, එය මනින ලද අක්‍රිය CPU වලින් වෙන්කර හඳුනාගත නොහැකිය; එකතු කිරීමේ තත්ත්වය සහ දන්නා හිස්-ප්‍රතිඵල දෝෂය සමඟ එය සහසම්බන්ධ කරන්න.

**ප්‍රොසෙසර දර්ශක ස්ථානීය වේ.** ඒවා සොයාගනු ලබන්නේ ප්‍රොසෙසර වගුව ඇවිදීමෙනි. නියෝජිත දර්ශක වෙනස් වුවහොත්, අඛණ්ඩතාව විශ්වාස කිරීමට පෙර අනන්‍යතා සිතියම්කරණය තහවුරු කරන්න. ඇසුරුම් කරන ලද ඉලක්කම් එකක්/දෙකක් සීමා කිරීම වෙනම සොයාගැනීමේ දෝෂයකි.

**ගබඩා ඇතුළත් කිරීම් යනු නියෝජිතයා ගබඩා ලෙස හඳුන්වන ඕනෑම දෙයකි.** ගුණ කිරීම අවශ්‍ය වන වෙන්කිරීමේ ඒකකවල, ඔබට අවශ්‍ය නොවූ දේවල් සමඟ මිශ්‍ර වූ දත්ත ගබඩා බලාපොරොත්තු වන්න. මෙය Host Resources හැසිරීම මිස ESXi විකාරයක් නොවේ. බයිට් අර්ථ නිරූපණය කිරීමට පෙර හැඹිලිගත වෙන්කිරීමේ ඒකක තහවුරු කරන්න; වලංගු නොවන සෘණ සාම්පල හෝ නැතිවූ ගුණකයන් සඳහා හවුල් ස්ක්‍රිප්ටයේ [දන්නා පරිවර්තන දෝෂයක්](https://github.com/kadupulhq/kadupul/issues/243) ඇත.

**හයිපර්වයිසර් එකක අතුරුමුහුණත් නම් වෙනස් වන තුරු ස්ථාවර වේ.** ධාවක යාවත්කාලීන කිරීමක් හෝ නැවත සකස් කිරීමක් මඟින් ඒවා නැවත අංකනය කළ හැක. දර්ශකය තෝරා ගන්නේ කෙසේද සහ එය වැදගත් වන්නේ ඇයිද යන්න සඳහා [ස්විචයක් නිරීක්ෂණය කිරීම](/si/guides/monitor-a-switch/) බලන්න.

**ස්ක්‍රිප්ට් ධාවනය වන්නේ පෝලර් ධාරකයේය.** හැඹිලිගත විධානය මඟින් සම්මත කරන ලද උපාංග ID භාවිතා කරමින් ඒවා හයිපර්වයිසර් වෙතම ළඟා වේ. ආගන්තුක සහ CPU-සාමාන්‍ය සහායකයින් එක් එක් ඇමතුමේදී වත්මන් උපාංග පේළිය ලබා ගනී; ප්‍රජා වෙනසක් සඳහා එම විධාන තර්ක නැවත ගොඩනැගීම අවශ්‍ය නොවේ. වෙනත් එකතු කරන්නන් ඔවුන්ගේ වැඩ අයිතමවල අක්තපත්‍ර කාවැද්දිය හැක.
