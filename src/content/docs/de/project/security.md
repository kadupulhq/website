Melden Sie Sicherheitslücken vertraulich, auch in unveröffentlichtem Code. Erstellen Sie vor der vertraulichen Prüfung weder ein öffentliches Issue noch veröffentlichen Sie einen Fix.

Diese Seite ist eine kurze Einführung. Weitere Einzelheiten stehen auf der vollständigen englischen Seite. [English](/project/security/)

[Sicherheitsrichtlinie des Repositorys](https://github.com/kadupulhq/kadupul/blob/main/SECURITY.md)

## Sicherheitslücke vertraulich melden

Nennen Sie Version oder Commit, Schritte zur Reproduktion, erforderliche Konfiguration und ob eine Anmeldung nötig ist. Die Verantwortlichen streben eine Eingangsbestätigung innerhalb von drei Arbeitstagen an; dies ist kein zugesagter Behebungstermin.

[Sicherheitslücke vertraulich melden](https://github.com/kadupulhq/kadupul/security/advisories/new)

Die Richtlinie umfasst Anwendung, Poller, Installationsprogramm und Paketierung. Ausgenommen sind Drittanbieter-Plugins, RRDtool, Net-SNMP, Webserver, Datenbank und Fälle, in denen ein Administrator gegen die eigene Installation handeln muss.
