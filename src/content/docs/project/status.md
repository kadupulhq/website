Kadupul is in pre-alpha. The source is available, but there is no supported release
or supported migration path. Do not run it in production.

## Release goals

- Test device polling, data collection, and graphing together.
- Validate plugin, template, and stored-data compatibility.
- Provide installation instructions and reversible migration tooling.
- Document release support and known limitations.

The software is GPL-3.0-or-later. See [License](/project/license/).
Documentation describing planned behavior is labeled accordingly.
