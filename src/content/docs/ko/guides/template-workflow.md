## 적절한 정의 선택

장치 템플릿은 그래프 템플릿과 데이터 쿼리를 제공하고 데이터 템플릿은 측정 입력과 저장을 정의합니다. 별도 식별자가 필요하면 비슷한 템플릿을 복제한 뒤 공유 종속성을 확인하세요. 복제해도 참조된 모든 입력이나 프로필이 독립되지는 않습니다. 사용 중인 정의를 변경하기 전에 내보내기와 일관된 데이터베이스/RRD 백업 세트를 보관하세요. 템플릿 개념을 참고하세요.

## 미리 본 뒤 신중히 적용

격리된 설치에서 XML 출처, 대상 식별자 및 선택한 저장 프로필을 검사하세요. 애플리케이션 루트에서 일반 템플릿 XML을 미리 봅니다.

```sh
php cli/import_template.php --filename=/secure/template.xml --preview
```

현재 `main`은 읽을 수 없는 입력, 잘못된 XML 및 기록된 객체 실패에 0이 아닌 상태를 반환합니다. 진단과 객체별 결과도 확인하세요. 가져오기는 기존 식별자를 갱신할 수 있습니다. 패키지 가져오기에는 별도 파일 쓰기 경로가 있습니다. 가져오기 및 내보내기를 참고하세요.

## 파생 객체와 이력 확인

적용 후 대표 장치, 로컬 그래프 항목 매핑, 개별 재정의 및 수집값을 확인하세요. 장치 템플릿 연결 변경에는 별도 동기화가 필요합니다. 데이터 템플릿 저장은 기존 RRD 구조를 변경하지 않습니다. 간격, heartbeat 또는 보존 기간을 바꾸기 전에 실제 파일을 검사하세요. 일관된 복구 전에 쓰기 프로세스를 중지하고 필요하면 맞춰진 백업 세트를 복원하세요. 사용자 지정 템플릿과 보존을 참고하세요.
