Kadupul focuses on network monitoring, reliable data collection, and maintainable
software. The first release aims to:

- Verify device polling, data collection, and graphing with automated tests.
- Improve security boundaries and replace error-prone subsystems.
- Use maintained libraries and supported language runtimes.
- Preserve plugin interfaces, templates, and recorded RRD data.
- Provide documented installation and reversible migration procedures.

These are goals, not a claim that the work is complete. See [Status](/project/status/)
and [Compatibility](/project/compatibility/) before planning an installation.
