## 適切な定義を選ぶ

デバイステンプレートはグラフテンプレートとデータクエリを提供し、データテンプレートは測定入力と保存を定義します。別の識別情報が必要なら近いものを複製し、共有される依存関係を確認してください。複製しても参照先の入力やプロファイルがすべて独立するわけではありません。使用中の定義を変更する前に、エクスポートと整合するデータベース/RRD バックアップを保管してください。テンプレートの概念を参照してください。

## プレビュー後に意図して適用する

隔離した環境で XML の出所、対象の識別情報、選択した保存プロファイルを確認します。アプリケーションのルートで通常のテンプレート XML をプレビューします。

```sh
php cli/import_template.php --filename=/secure/template.xml --preview
```

現在の `main` は、読めない入力、不正な XML、記録されたオブジェクト失敗に対してゼロ以外の状態を返します。診断とオブジェクトごとの結果も確認してください。インポートは既存の識別情報を更新することがあります。パッケージインポートには別のファイル書き込み経路があります。インポートとエクスポートを参照してください。

## 派生オブジェクトと履歴を確認する

適用後は代表的な機器、ローカルのグラフ項目対応、個別設定、収集値を確認します。デバイステンプレートの関連付け変更には別途同期操作が必要です。データテンプレートの保存では既存 RRD の構造は変わりません。ステップ、heartbeat、保持期間を変える前に実ファイルを確認してください。整合性を保った復旧の前には書き込み処理を停止し、必要なら対応するバックアップ一式を復元します。独自テンプレートと保持期間を参照してください。
