Segnala le vulnerabilità in privato, anche se riguardano codice non ancora pubblicato. Non aprire una segnalazione pubblica né pubblicare correzioni prima della valutazione privata.

## Segnala una vulnerabilità in privato

Includi versione o commit, passaggi per riprodurre il problema, configurazione necessaria ed eventuale necessità di autenticazione. I responsabili mirano a confermare la ricezione entro tre giorni lavorativi; non è una scadenza garantita per la correzione.

[Segnala una vulnerabilità in privato](https://github.com/kadupulhq/kadupul/security/advisories/new)

La politica copre applicazione, raccoglitore, programma di installazione e creazione dei pacchetti. Esclude plugin di terzi, RRDtool, Net-SNMP, server web, database e casi che richiedono a un amministratore di agire contro la propria installazione.
