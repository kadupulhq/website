## निष्पादन वातावरण चुनें

वर्तमान `main` को PHP 8.4+, `pcntl` और `posix` चाहिए; नेटिव Windows PHP ये Unix आवश्यकताएँ पूरी नहीं करता। Composer की प्लेटफ़ॉर्म जाँच न छोड़ें। Linux VM उपयोग करें या Microsoft-समर्थित Windows पर WSL 2 का मूल्यांकन करें। ये Windows पर होस्ट किए Linux इंस्टॉलेशन हैं, सत्यापित नेटिव IIS डिप्लॉयमेंट नहीं। PHP की प्लेटफ़ॉर्म सीमाएँ देखें।

## Linux तैयार करें, फिर इंस्टॉल करें

WSL के लिए व्यवस्थापक PowerShell में यह चलाएँ और कहा जाए तो रीस्टार्ट करें:

```powershell
wsl --install -d Ubuntu
wsl --list --verbose
```

संस्करण 2 सुनिश्चित करें। Linux खाता सेटअप पूरा करें और Linux के भीतर इंस्टॉलेशन का पालन करके डेटाबेस, PHP एक्सटेंशन, संसाधन, वेब सर्वर और शेड्यूलर बनाएँ। कोड और RRD स्टोरेज Linux फ़ाइल सिस्टम में रखें, `/mnt/c/` के नीचे नहीं। Microsoft की WSL और फ़ाइल सिस्टम मार्गदर्शिकाएँ देखें।

## जीवनचक्र और रिकवरी जाँचें

समर्पित विशेषाधिकार-रहित खाते और एक संग्रह लॉन्च व्यवस्था उपयोग करें। होस्ट रीबूट या WSL बंद होने के बाद स्टोरेज विश्वास, पोलिंग, ग्राफ़ टाइमस्टैम्प और पुनः चालू होना सत्यापित करें। डेस्कटॉप सत्र से संग्रह चलते रहने की धारणा न बनाएँ। डेटाबेस, कॉन्फ़िगरेशन और RRD का संयुक्त बैकअप लें। नेटिव Windows पर विनाशकारी RRD रखरखाव और स्वचालित स्थानीय पर्ज/आर्काइव उपलब्ध नहीं हैं; Linux का व्यवहार इन्हें सत्यापित नहीं करता। आवश्यकताएँ और बैकअप देखें।
