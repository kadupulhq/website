## නිවැරදි අර්ථදැක්වීම් තෝරන්න

උපාංග සැකිලි ප්‍රස්තාර සැකිලි සහ දත්ත විමසුම් ලබා දෙයි; දත්ත සැකිලි මිනුම් ආදාන සහ ගබඩාව අර්ථ දක්වයි. වෙනම අනන්‍යතාවක් අවශ්‍ය නම් සමාන සැකිල්ලක් අනුපිටපත් කර බෙදාගත් පරායත්තතා බලන්න. පිටපතක් සෑම යොමු කළ ආදානයක් හෝ පැතිකඩක්ම ස්වාධීන නොකරයි. භාවිතයේ ඇති අර්ථදැක්වීම් වෙනස් කිරීමට පෙර අපනයනයක් සහ ගැළපෙන දත්ත සමුදා/RRD උපස්ථයක් තබාගන්න. සැකිලි සංකල්ප බලන්න.

## පෙරදසුන බලා සැලකිල්ලෙන් යොදන්න

වෙන් කළ ස්ථාපනයක XML ප්‍රභවය, ගමනාන්ත අනන්‍යතා සහ තෝරාගත් ගබඩා පැතිකඩ පරීක්ෂා කරන්න. යෙදුම් මූලයේ සිට සාමාන්‍ය සැකිලි XML පෙරදසුන බලන්න:

```sh
php cli/import_template.php --filename=/secure/template.xml --preview
```

වත්මන් `main` කියවිය නොහැකි ආදාන, වැරදි XML සහ වාර්තා වූ වස්තු අසාර්ථකවීම් සඳහා ශුන්‍ය නොවන තත්ත්වයක් ලබා දෙයි. දෝෂ විස්තර සහ එක් එක් වස්තුවේ ප්‍රතිඵල ද බලන්න; ආයාතයක් පවතින අනන්‍යතා යාවත්කාලීන කළ හැකිය. පැකේජ ආයාතයට වෙනම ගොනු ලිවීමේ මාර්ගයක් ඇත. ආයාත සහ අපනයන බලන්න.

## උප වස්තු සහ ඉතිහාසය පරීක්ෂා කරන්න

යෙදීමෙන් පසු නියෝජිත උපාංග, දේශීය ප්‍රස්තාර අංග සිතියම්කරණ, තනි සැකසුම් සහ රැස් කළ අගයන් බලන්න. උපාංග සැකිලි සම්බන්ධතා වෙනස්කම් සඳහා වෙනම සමමුහුර්ත කිරීමක් අවශ්‍යයි. දත්ත සැකිල්ල සුරැකීමෙන් පවතින RRD ව්‍යුහය වෙනස් නොවේ; පියවර, heartbeat හෝ රඳවාගැනීම වෙනස් කිරීමට පෙර සැබෑ ගොනුව බලන්න. සම්බන්ධීකෘත ප්‍රතිසාධනයකට පෙර ලිවීමේ ක්‍රියාවලි නවත්වා අවශ්‍ය නම් ගැළපෙන උපස්ථ එකතුව ප්‍රතිස්ථාපනය කරන්න. අභිරුචි සැකිලි සහ රඳවාගැනීම බලන්න.
