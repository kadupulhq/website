Kadupul は Cacti から派生した独立プロジェクトです。デバイスを定期的に照会し、RRDtool で測定値を保存・表示します。

このページは概要です。詳しくは英語の完全版を参照してください。 [English](/start/what-kadupul-is/)

## Kadupul とは

- PHP アプリケーションが画面とインストーラーを提供します。
- MySQL または MariaDB に設定、ユーザー、ポーラーのキャッシュを保存します。
- RRD ファイルは設定された保持期間と集約規則に従って測定値を保存します。すべてのデータを永久に保持するわけではありません。
- スケジューラーがポーラーを起動します。収集スクリプトはポーラーのシステムユーザー権限で実行されます。

## はじめに

まず隔離したテスト環境を構築し、デバイスを追加します。データの到着を確認してからグラフを読み取ってください。バックアップを保存し、復元を検証してください。
