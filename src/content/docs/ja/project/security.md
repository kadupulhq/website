## 脆弱性を非公開で報告

バージョンまたはコミット、再現手順、必要な設定、認証の要否を記載してください。保守担当者は三営業日以内の受領確認を目指しますが、修正日の保証ではありません。

[脆弱性を非公開で報告](https://github.com/kadupulhq/kadupul/security/advisories/new)

対象はアプリケーション、ポーラー、インストーラー、パッケージ作成処理です。第三者のプラグイン、RRDtool、Net-SNMP、Web サーバー、データベース、および管理者が自身の環境を害する操作を必要とする問題は対象外です。
