## اختيار التعريفات المناسبة

توفّر قوالب الأجهزة قوالب الرسوم واستعلامات البيانات؛ وتحدد قوالب البيانات مدخلات القياس والتخزين. انسخ قالبًا قريبًا عندما تحتاج إلى هوية مستقلة، ثم راجع الاعتماديات المشتركة. النسخ لا يجعل كل مدخل أو ملف تعريف مشار إليه مستقلًا. احتفظ بتصدير ونسخة احتياطية متطابقة لقاعدة البيانات وRRD قبل تغيير تعريفات مستخدمة. راجع مفاهيم القوالب.

## المعاينة ثم التطبيق المقصود

في تثبيت معزول، افحص مصدر XML والهويات المستهدفة وملف التخزين المختار. من جذر التطبيق اعرض معاينة XML للقالب البسيط:

```sh
php cli/import_template.php --filename=/secure/template.xml --preview
```

يرجع `main` الحالي حالة غير صفرية للمدخلات غير المقروءة وXML غير السليم وإخفاقات الكائنات المسجلة. افحص أيضًا التشخيصات ونتيجة كل كائن؛ فقد يحدّث الاستيراد هويات موجودة. لاستيراد الحزم مسار منفصل لكتابة الملفات. راجع الاستيراد والتصدير.

## التحقق من الكائنات المشتقة والسجل

بعد التطبيق افحص أجهزة ممثلة وربط عناصر الرسوم المحلي والتجاوزات الفردية والقيم المجمعة. تتطلب تغييرات ارتباط قوالب الأجهزة عملية مزامنة منفصلة. حفظ قالب البيانات لا يعيد تشكيل RRD الحالية؛ افحص الملف الفعلي قبل تغيير الخطوة أو heartbeat أو الاحتفاظ. أوقف عمليات الكتابة قبل استعادة منسقة، واستعد مجموعة النسخ المتطابقة عند الحاجة. راجع القوالب المخصصة والاحتفاظ.
