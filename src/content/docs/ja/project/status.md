Kadupul はプレアルファ段階です。ソースコードは公開されていますが、サポート対象のリリースや検証済みの本番移行手順はありません。本番環境では使用しないでください。

このページは概要です。詳しくは英語の完全版を参照してください。 [English](/project/status/)

## プロジェクトの状況

アプリケーションは Cacti 1.2.31 に由来します。main は開発用で、lts/1.2 は修正とセキュリティ強化を受け取ります。バージョン方針ではそれぞれ v1.3.0 と v1.2.32 が予定されています。予定の番号は公開済みリリースの証拠ではありません。

Kadupul は Spine のフォークを保守する予定です。リポジトリの場所と検証済みビルドは、今後ドキュメントに記載する必要があります。プラグイン、テンプレート、データベース、RRD データの互換性は目標であり、移行ごとの検証が必要です。

現在の約束事項はリポジトリの方針を確認してください。自動テストやパッケージ作成ツールが存在しても、移行の安全性が証明されたことにはなりません。
