ප්‍රභව කේතය ලබා ගත හැකි නමුත් සහය දක්වන Kadupul නිකුතුවක් හෝ සංක්‍රමණ මාර්ගයක් නොමැත. මේවා මත විශ්වාසය තැබීමට පෙර උපස්ථ සහිත හුදකලා පිටපතක මෙම ක්‍රියා පටිපාටි පරීක්ෂා කරන්න. [ව්‍යාපෘති තත්ත්වය](/si/project/status/) බලන්න.
:::

SNMP හරහා Windows අතුරුමුහුණත්, ප්‍රොසෙසර, ආචයනය සහ සමහර ගණක සපයයි. තනා ඇති Microsoft නියෝජිතයා net-snmp UCD සැකිලිවල භාර, මතක සහ තැටි වස්තු නිරාවරණය නොකරයි. නියෝජිතයා ඒවා නිරාවරණය කරන්නේ නම් ආචයන පේළි වලින් මතකය තවමත් ප්‍රස්ථාරගත කළ හැකිය. තෙවන පාර්ශවීය නියෝජිතයින් වෙනත් වස්තු සැපයිය හැකිය; සැකිලි තෝරා ගැනීමට පෙර සැබෑ නියෝජිතයා පරීක්ෂා කරන්න.

## SNMP සේවාව සපයන දේ

Windows SNMP සේවාව යල් පැන ගිය අතර එය විකල්පමය වේ. Windows 10 සහ 11 සඳහා, Microsoft විසින් විකල්ප විශේෂාංග හෝ Windows විශේෂාංග හරහා එය ස්ථාපනය කිරීම ලේඛනගත කරයි; පැරණි DISM විශේෂාංග නාම දෝෂයක් පමණක් එය නොමැති බව ඔප්පු නොකරයි. ඔබගේ Windows සංස්කරණය සඳහා සුදුසු උපදෙස් පරීක්ෂා කරන්න. [Microsoft හි SNMP ස්ථාපන මාර්ගෝපදේශය](https://learn.microsoft.com/en-us/troubleshoot/windows-client/networking/cannot-install-snmp-wmisnmpprovider) බලන්න.

ඔබ ස්ථාපනය කර ඇති නියෝජිතයා මෙම උප-වෘක්ෂයන්ගෙන් කවරක් නිරාවරණය කරන්නේදැයි පරීක්ෂා කරන්න:

| ප්‍රදේශය | උප-වෘක්ෂය | සපයන දේ |
|---|---|---|
| පද්ධතිය | `.1.3.6.1.2.1.1` | විස්තරය, ක්‍රියාකාරී කාලය, සම්බන්ධතාවය, නම, ස්ථානය |
| අතුරුමුහුණත් | `.1.3.6.1.2.1.2` සහ `.1.3.6.1.2.1.31` | ගමනාගමනය, දෝෂ, තත්ත්වය |
| ධාරක සම්පත් | `.1.3.6.1.2.1.25` | ප්‍රොසෙසර, ආචයනය, ක්‍රියාවලි ගණන, ප්‍රවිෂ්ට වූ පරිශීලකයින් |
| LAN Manager | `.1.3.6.1.4.1.77` | Windows සේවා සහ බෙදාගැනීමේ දත්ත |

Kadupul හි සපයා ඇති Windows සැකිලි පළමු ප්‍රදේශ තුන කියවයි. ඇතුළත් කර ඇති කට්ටලයේ කිසිවක් LAN Manager උප-වෘක්ෂය කියවන්නේ නැත.

ධාරකයේ ඇති වින්‍යාස අයිතම දෙකක් ඔබට දත්ත ලැබෙන්නේද යන්න තීරණය කරයි: ප්‍රජා තන්තුව (community string) සහ නියෝජිතයා පැකට් පිළිගන්නා කළමනාකරුවන්ගේ ලැයිස්තුව. තනි කළමනාකරු ලිපිනයකින් පමණක් SNMP පිළිගැනීමට සකසා ඇති ධාරකයක් ප්‍රතිචාර දක්වන්නේ එම කළමනාකරුට පමණක් වන අතර අනෙක් සියල්ල අත්හරියි.

ප්‍රස්ථාර සෑදීමට පෙර poller ධාරකයේ සිට එක් එක් ප්‍රදේශය සත්‍යාපනය කරන්න. උදාහරණ ධාරකය සහ ප්‍රජාව ඔබගේ වින්‍යාසගත අගයන් සමඟ ප්‍රතිස්ථාපනය කරන්න; `public` යනු නිදර්ශනය සඳහා පමණි.

```bash
snmpget  -v2c -c public win.example.net .1.3.6.1.2.1.1.1.0
snmpwalk -v2c -c public win.example.net .1.3.6.1.2.1.25.3.3.1.2
snmpwalk -v2c -c public win.example.net .1.3.6.1.2.1.25.2.3.1.3
```

දෙවන walk එක ප්‍රොසෙසර් භාරය කියවයි, තුන්වන එක ආචයන විස්තර ලැයිස්තුව කියවයි. පළමු විධානය ක්‍රියාත්මක වන අතර අනෙක් දෙක කිසිවක් ලබා නොදෙන්නේ නම්, ප්‍රවේශ සීමාවන්, නියෝජිත සහාය සහ ආපසු ලබා දුන් SNMP දෝෂය පරීක්ෂා කරන්න.

## උපාංගය එකතු කිරීම

සැකිලි නොමැති නම්, [සැකිලි ආයාත කිරීම සහ අපනයනය කිරීම](/si/guides/import-and-export-templates/) අනුව `install/templates/Windows_Device.xml.gz` ආයාත කරන්න. Windows උපාංග සැකිල්ල තෝරන්න, විමසුම් සොයා ගැනීම තහවුරු කරන්න, ඉන්පසු ඔබට අවශ්‍ය ප්‍රස්ථාර පැහැදිලිව සාදන්න. පැකේජයේ දත්ත විමසුම් තුනක් සහ ඒවාට අදාළ ප්‍රස්ථාර සැකිලි අඩංගු වේ.

**විශාල හෝ අවලංගු ආචයන අගයන් සත්‍යාපනය අවශ්‍ය වේ.** MIB ප්‍රමාණය සහ භාවිතය සෘණ නොවන Integer32 ලෙස අර්ථ දක්වයි. සෘණ අගයක් ලබා දෙන නියෝජිතයෙකු එම පරාසයෙන් පිටත වේ. වත්මන් ස්ක්‍රිප්ට් එක `(abs(value) + 2147483647) * allocation_units` භාවිතා කරයි, එය ලකුණු නොකළ 32-බිට් නැවත අර්ථකථනයක් නියෝජනය නොකරයි. බලපෑමට ලක් වූ අගයන් විශ්වාස කළ නොහැකි ලෙස සලකන්න සහ සොයා ගැනීම නිවැරදි කිරීමෙන් පසු නැවත සුචිගත කරන්න. ### අතුරුමුහුණත්

අතුරුමුහුණත් විමසුම ස්විචයක් භාවිතා කරන ආකාරයටම සමාන වේ. එහි දර්ශක මනාප අනුපිළිවෙල වන්නේ `ifName`, පසුව `ifDescr`, පසුව `ifHwAddr`, පසුව `ifIndex` යන්නයි. එය සොයාගත් සෑම අතුරුමුහුණතකම පවතින සහ අනන්‍ය වූ පළමු ක්ෂේත්‍රය තෝරා ගනී.

Windows යනු මෙය බොහෝ විට අසාර්ථක වන වේදිකාවයි. සමාන NIC දෙකකට එකම `ifDescr` ආපසු ලබා දිය හැකි අතර සමහර නියෝජිතයින් `ifName` හිස්ව තබයි. විමසුම `ifIndex` වෙත ආපසු පැමිණි විට, ඔබගේ අතුරුමුහුණත් ඉතිහාසය Windows හට නිදහසේ නැවත පැවරිය හැකි අංකයකට බැඳී ඇත.

[ස්විචයක් නිරීක්ෂණය කිරීම](/si/guides/monitor-a-switch/) සහ [දත්ත විමසුම් සහ දර්ශක](/si/concepts/data-queries-and-indexes/) බලන්න.

## SNMP නොමැති විට

බොහෝ Windows ස්ථාපනයන්හි SNMP සේවාව සක්‍රීය කර නොමැත. ආදේශකය ස්ක්‍රිප්ට් ආදානයකි.

කරුණු දෙකක් ඔබ ස්ක්‍රිප්ට් ලියන ආකාරය තීරණය කරයි.

**ස්ක්‍රිප්ට් එක ක්‍රියාත්මක වන්නේ poller ධාවනය වන පරිගණකයේය.** Windows ධාරකය වෙත ළඟා වීම ඔබේ ස්ක්‍රිප්ට් එකේ කාර්යයයි: WinRM, නියෝජිතයෙකු, HTTP අන්ත ලක්ෂ්‍යයක්, බෙදාගැනීමක් හෝ ඔබ ක්‍රියාත්මක කරන ඕනෑම යාන්ත්‍රණයක්.

**සම්මත ප්‍රතිදානය මත මිනුම් නිකුත් කරන්න.** PHP poller හි බාහිර විධාන මාර්ගය පිටවීමේ තත්ත්වය මිනුම් අගයක් ලෙස භාවිතා නොකරයි. සංඛ්‍යාවක් නිකුත් කරන්න, නැතහොත් මෙම චක්‍රයේ කිසිදු මිනුමක් සඳහා `U` නිකුත් කරන්න. මිනුම අසාර්ථක වූ බව දැක්වීමට ඔබට අවශ්‍ය වූ විට `0` නිකුත් නොකරන්න.

තනි සංඛ්‍යාවක් වෙනුවට අතුරුමුහුණතකට, තැටියකට හෝ සේවාවකට අගයක් අවශ්‍ය නම්, එම ස්ක්‍රිප්ට් යාන්ත්‍රණයම සුචිගත කළ ආකෘතියක් සපයයි. `resource/script_queries/host_cpu.xml` යනු ස්ක්‍රිප්ට් සේවාදායකය වෙනුවට PHP ස්ක්‍රිප්ට් එකක් අමතන ප්‍රායෝගික උදාහරණයකි.

ප්‍රතිදාන ගිවිසුම සහ නාමකරණ බාධාවන් සඳහා [දත්ත එකතු කිරීමේ ස්ක්‍රිප්ට් ලිවීම](/si/guides/write-a-data-collection-script/) බලන්න.
