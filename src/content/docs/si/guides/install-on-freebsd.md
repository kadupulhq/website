## ධාරකය තෝරා සූදානම් කරන්න

FreeBSD සහාය නිකුතු වගුවේ අනුවාදයක් භාවිත කර 2027 දක්වා උත්ශ්‍රේණි සැලසුම් කරන්න. OS සහාය Kadupul ගැළපීම තහවුරු නොකරයි. Packages and Ports අත්පොත අනුව PHP 8.4+, MySQL හෝ MariaDB, RRDtool, Net-SNMP සහ වෙබ් සේවාදායකයක් ස්ථාපනය කරන්න. `php84-extensions` පෙරනිමි අගයන් සම්පූර්ණ යෙදුම් දිගු ලැයිස්තුව නොවේ; පරායත්තතා ස්ථාපනයට පෙර CLI සඳහා `pcntl` ඇතුළු නොමැති මොඩියුල ස්ථාපනය කරන්න.

## ධාවන පරිසරය බලමින් සේවා සකසන්න

තෝරාගත් CLI අර්ථකථකය සහ මෙවලම් පරීක්ෂා කරන්න:

```sh
php -v
php -m
rrdtool --version
snmpget --version
```

වෙබ් PHP වෙනම බලන්න. පැකේජ PHP-FPM සඳහා `php_fpm` සේවාව සක්‍රිය කිරීමට පෙර pool සහ වෙබ් සේවාදායක සම්බන්ධය සකසන්න. FreeBSD systemd වෙනුවට rc සේවා භාවිත කරයි; සේවා අත්පොත අනුගමනය කරන්න. දත්ත සමුදාය, වින්‍යාසය, ව්‍යුහය සහ බ්‍රවුසර සම්පත් සඳහා ස්ථාපන උපදෙස් අනුගමනය කරන්න. මෙවලම් යෙදුමේ `mise.toml` සමඟ ගළපන්න; එම ස්ථාවර අනුවාදයන් mise ධාවන ස්ථාපක FreeBSD මත වැඩ කරන බවට සාක්ෂි නොවේ.

## සේවා ගිණුම්වලින් කාලසටහන සහ තහවුරු කිරීම

නිරපේක්ෂ ක්‍රියාත්මක මාර්ග සහ සැකසූ පරතරය සහිත එක cron ආරම්භකයක් භාවිත කරන්න; Linux systemd ඒකකය ස්ථාපනය නොකරන්න. රැස්කිරීමට පෙර සෑම වෙබ්/poller ගිණුමකින්ම POSIX අනන්‍යතාව, නාමාවලි අගුළු, හිමිකම සහ පැහැදිලි UID/GID විශ්වාසය තහවුරු කරන්න. jail සඳහා එහි ඇතුළත ජාලය, mount සහ අවසර බලන්න. එකිනෙක නොගැටෙන චක්‍රයක් ධාවනය කර ඉතිරි පෝලිම් පේළි සහ ප්‍රස්තාර වේලා මුද්‍රා බලන්න; ගැළපෙන උපස්ථ ප්‍රතිස්ථාපනය පෙරහුරු කරන්න. ක්‍රියාවලිය සාර්ථකව ආරම්භ වීම පමණක් ප්‍රමාණවත් නැත. අවශ්‍යතා සහ උපස්ථ බලන්න.
