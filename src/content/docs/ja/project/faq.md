## プロジェクト全般

### 今すぐインストールできますか？

開発および独立したテスト環境向けにソースコードが公開されています。サポート対象のリリースや、検証済みの本番環境向けインストール手順はまだありません。

インストールおよびハウツー記事は、実際に使用するコードに照らして検証する必要があります。[ステータス](/ja/project/status/)を参照してください。

### 本番環境で使用できますか？

いいえ。リポジトリでは Kadupul をプレアルファ段階であり、本番環境への投入準備は整っていないと説明しています。リリースステータスは、誰かが開発コードをデプロイしたかどうかを示すものではありません。

### これは Cacti の代替品ですか？

Kadupul は独自の開発優先順位とサポートチャネルを持つ独立したフォークです。プレアルファ段階であるため、移行には使用するバージョンおよび拡張機能の検証が必要です。[Cacti からの移行](/ja/guides/coming-from-cacti/)を参照してください。

### なぜ別のプロジェクトなのですか？

Kadupul は独自のリリース方針の下で、サブシステムの置換、言語基準の引き上げ、内部インターフェースの変更を行う場を提供します。[このフォークが存在する理由](/ja/project/why-this-fork/)を参照してください。

### どの Cacti バージョンからフォークしたのですか？

本アプリケーションは Cacti 1.2.31 から派生しています。リポジトリは異なるリリース目標を持つ `main` および `lts/1.2` の各系統を維持しています。[ステータス](/ja/project/status/)を参照してください。

### 誰が保守していますか？

Kadupul プロジェクトがリポジトリを保守しています。プロジェクト関連の作業には、課題トラッカーおよび[コントリビューションプロセス](/ja/project/contributing/)を利用してください。

### ロードマップ、リリースペース、サポートポリシーはありますか？

リポジトリにはリリース目標、バージョン管理方針、コントリビューションプロセスが用意されています。サポート対象の本番リリースはまだありません。計画されているバージョンと公開されている成果物の区別については、[ステータス](/ja/project/status/)を参照してください。

### The Cacti Group と提携していますか？

いいえ。Kadupul は The Cacti Group との提携関係はなく、推奨も受けていません。コードの起源に関する事実であるため、自らを Cacti のフォークと説明しています。Cacti は彼らのプロジェクトであり、彼らの名前です。

### 名前の由来は何ですか？

Kadupul は夜に咲くサボテンを表すシンハラ語の名称です。Cacti の名は植物の「科」全体に由来し、Kadupul はその中の一つの「種」です。この名称は、全体を代表すると主張することなくプロジェクトの出自を表しています。詳細は [Kadupul とは](/ja/start/what-kadupul-is/)に記載されています。

## Cacti からの移行

### 既存のプラグインは動作しますか？

それが意図されている目標です。プラグイン API は 4 つの互換性目標の 1 つです。Cacti プラグインを変更せずに読み込み実行できることは、使用するバージョンにおいて実証される必要があります。

互換性は目標であり、あらゆるプラグインに対する一律の保証ではありません。移行を計画する前に、実際に依存しているプラグインとバージョンを確認してください。[Cacti との互換性](/ja/project/compatibility-with-cacti/)および [Cacti からの移行](/ja/guides/coming-from-cacti/)を参照してください。

### 既存の RRD ファイルは動作しますか？

RRD 履歴の保持は互換性の目標です。これらのファイルには再生成できない履歴が含まれています。移行前にコピー環境で既存ファイルの読み取りを検証してください。

ファイルを破棄して再作成することを求める移行手順は、拒否すべき要求です。[Cacti からの移行](/ja/guides/coming-from-cacti/)を参照してください。

### テンプレートとデータベースは引き継がれますか？

テンプレートは変更なしでインポートできることを想定しています。スキーマは中間形式へのエクスポートなしで認識および移行できる状態を保つよう意図されています。これらはプラグインや RRD ファイルと同様に検証が必要な目標です。

### Kadupul と Cacti の違いはどこで確認できますか？

文書化されている内容を通じて確認できます。プロジェクトが避けようとしている障害モードは、フォークの目的そのものである機能の分岐ではなく、誰も記録しなかった機能の分岐です。記録のない分岐は、すべてのアップグレードを調査作業に変えてしまいます。

### Spine と連携して動作しますか？

Kadupul は PHP コレクターと並行して Spine フォークを保守する予定です。そのリポジトリの場所と検証済みビルドは、ここではまだ文書化されていません。Spine は別途ビルドおよびインストールされます。継承された統合には、`poller_type` およびパス設定、親ポーラーのコマンドライン、Spine が読み取る設定、および書き込むテーブルが含まれます。

本番切り替えの前に、Kadupul と Spine のバージョンを組み合わせて検証してください。問題は [Kadupul の課題トラッカー](https://github.com/kadupulhq/kadupul/issues)に報告してください。設定とビルドのガイダンスについては [Spine（C 言語コレクター）](/ja/reference/spine/)を参照してください。

### RRDtool プロキシと連携して動作しますか？

Kadupul は Cacti 組織のプロキシデーモンを使用しません。ローカルの RRDtool ストレージを使用してください。[RRDtool プロキシリファレンス](/ja/reference/rrdproxy/)は継承されたクライアントプロトコルを記録していますが、サポートされている展開オプションではありません。プロキシの展開が文書化される前に、Kadupul 独自の代替手段を確立し検証する必要があります。

### 動作に必要な環境は何ですか？

PHP、MySQL または MariaDB、RRDtool を備えた Web サーバー、およびスケジュールに従ってポーラーを実行する仕組みです。バージョンと必要な拡張機能は[システム要件](/ja/reference/requirements/)に記載されています。

## ライセンス体系

### ソフトウェアのライセンスは何ですか？

GPL-3.0-or-later です。

### Cacti は GPL-2 と表記されています。フォークが GPL-3 になるのはなぜですか？

継承元のアプリケーションライセンスは、GPL バージョン 2 またはそれ以降を許可しています。Kadupul は配布にあたり以降のバージョンを選択するオプションを採用しています。依存関係は独自のライセンス条項を保持します。[ライセンス](/ja/project/license/)を参照してください。

### 本ドキュメントのライセンスは何ですか？

CC BY-SA 4.0 です。サイト自体のコードは、プロジェクトの残りの部分とともに GPL-3.0-or-later のままです。プロジェクトをクレジット表示し、作成したものを同じ条件でライセンスする場合は、テキストを再利用できます。

### これらのページはどこから作成されたのですか？

これらのページはアプリケーションのソースコードから動作を記述しています。サードパーティの文章を再利用する場合は、事前に独自のライセンス確認が必要です。

この制約はコントリビューションにも適用されます。ドキュメントの変更は、コードに基づいて主張を裏付ける必要があります。[コントリビューション](/ja/project/contributing/)を参照してください。

## 参加方法

### 脆弱性はどのように報告すればよいですか？

該当するリポジトリの GitHub Security Advisories を通じて非公開で報告してください。公開の Issue として提出しないでください。

未リリースのコードであっても展開されて脆弱性が含まれている可能性があります。リリース状況にかかわらず非公開で報告してください。[セキュリティポリシー](/ja/project/security/)を参照してください。

### 発見した脆弱性が Cacti にも影響している可能性がある場合、どうすればよいですか？

Kadupul に非公開で報告し、共有コードについて把握している内容を含めてください。Kadupul のメンテナーは、[リポジトリセキュリティポリシー](https://github.com/kadupulhq/kadupul/blob/main/SECURITY.md)に基づいて Kadupul 向けのトリアージと修正対応を行います。

### どのように開発に参加できますか？

[コントリビューション](/ja/project/contributing/)および対象ブランチのコントリビューターガイドをお読みください。実質的な変更を行う前に事前に議論してください。
