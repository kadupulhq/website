## اختيار المضيف وتجهيزه

استخدم إصدارًا مدرجًا في جدول FreeBSD المدعوم وخطّط لترقياته حتى 2027. دعم نظام التشغيل لا يثبت توافق Kadupul. ثبّت PHP 8.4+ وMySQL أو MariaDB وRRDtool وNet-SNMP وخادم ويب وفق دليل Packages and Ports. إعدادات `php84-extensions` الافتراضية ليست قائمة امتدادات التطبيق الكاملة؛ ثبّت الوحدات الناقصة، ومنها `pcntl` لسطر الأوامر، قبل الاعتماديات.

## فحص التشغيل وتهيئة الخدمات

افحص مفسّر CLI والأدوات المختارة:

```sh
php -v
php -m
rrdtool --version
snmpget --version
```

افحص PHP للويب بشكل منفصل. بالنسبة إلى PHP-FPM المثبت كحزمة، اضبط مجموعة عملياته واتصال خادم الويب قبل تمكين خدمة `php_fpm`. يستخدم FreeBSD خدمات rc وليس systemd؛ اتبع دليل الخدمات. اتبع التثبيت لقاعدة البيانات والإعدادات والمخطط وموارد المتصفح. طابق الأدوات مع `mise.toml` للتطبيق؛ تثبيت الإصدارات لا يثبت أن برامج تثبيت بيئات mise تعمل على FreeBSD.

## الجدولة والتحقق بحسابات الخدمة

استخدم مشغل cron واحدًا بمسارات تنفيذ مطلقة والفاصل المضبوط؛ لا تثبّت وحدة Linux systemd. قبل الجمع تحقّق من هوية POSIX وقفل الأدلة والملكية وثقة UID/GID الصريحة بكل حساب ويب/استقصاء. في jails افحص الشبكة والربط والأذونات من الداخل. شغّل دورة واحدة دون تداخل، وافحص صفوف الطابور المحتفظ بها وطوابع الرسوم، ثم تدرب على استعادة نسخ متطابقة. مجرد بدء العملية بنجاح لا يكفي. راجع المتطلبات والنسخ الاحتياطي.
